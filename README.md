# 📺 Dark TV Pro - اپلیکیشن اندروید و اندروید تی‌وی (Android & Android TV)

نسخه نیتیو، فوق‌سبک و حرفه‌ای تلویزیون آنلاین بر پایه **Kotlin + Jetpack Compose + Media3 ExoPlayer** که تمام منطق پروکسی و ترمیم خودکار پورت (Auto-Healing) اسکریپت پایتون شما را مستقیماً در دل اندروید (بدون نیاز به سرور واسط!) اجرا می‌کند.

---

## ✨ ویژگی‌های کلیدی این پروژه

1. **بدون نیاز به سرور پایتون (Native Anti-Block & Auto-Healing):**
   * تمام هدرهای امنیتی (`Referer: https://mytvsat.tv/`, `Origin`, `User-Agent`) و دور زدن خطای SSL مستقیماً داخل `OkHttpDataSource` در فایل `NetworkHelper.kt` پیاده‌سازی شده‌اند.
   * **سیستم هوشمند ترمیم پورت:** دقیقاً مانند کد پایتون شما، اگر شبکه‌ای روی پورت `8080` خطا بدهد، پلیر به صورت خودکار و بدون دخالت کاربر در کسری از ثانیه پورت `80` را جایگزین و پخش می‌کند (و بالعکس).

2. **سازگاری ۱۰۰٪ با اندروید تی‌وی (Android TV) و موبایل:**
   * دارای `LEANBACK_LAUNCHER` و بنر اختصاصی تلویزیون در منوی اصلی Android TV.
   * پشتیبانی کامل از **ریموت کنترل تلویزیون (D-Pad)**:
     * دکمه‌های `CH+ / CH-` یا `PageUp / PageDown` برای تعویض سریع کانال‌ها (Zapping).
     * دکمه `Menu` یا جهت راست برای باز و بسته کردن لیست شبکه‌ها.
     * هایلایت نئونی واضح هنگام حرکت روی دکمه‌ها با کنترل تلویزیون.
   * طراحی واکنش‌گرا (Responsive): در موبایل به صورت عمودی (ویدیو بالا، لیست پایین) و در تلویزیون یا حالت افقی موبایل به صورت تمام‌صفحه با منوی کشویی شیشه‌ای (Glassmorphism) نمایش داده می‌شود.

3. **نام‌های کامل و لوگوهای اختصاصی + قابلیت جایگزینی آسان:**
   * تمام ۲۷ شبکه با نام فارسی و انگلیسی دقیق (مثل *رادیو جوان، تونل زمان، ام‌بی‌سی پرشیا، جم فود، جم فیت، آی‌سی‌سی، گرند سینما* و...) دسته‌بندی شده‌اند.
   * برای حفظ **کمترین حجم ممکن اپلیکیشن**، لوگوهای برداری و گرادینت اختصاصی برای هر شبکه طراحی شده است. همچنین فیلد `logoUrl` در فایل `ChannelData.kt` قرار داده شده تا اگر لینک عکس دلخواهی داشتید، کافیست لینک را قرار دهید تا خودکار لود شود.

4. **پلیر حرفه‌ای (ExoPlayer Media3):**
   * تغییر نسبت تصویر (اصلی، پر کردن صفحه، زوم) با یک کلیک.
   * بافرینگ بهینه‌شده برای استریم‌های زنده HLS.
   * قابلیت جستجوی سریع و فیلتر بر اساس دسته‌بندی (موزیک، فیلم و سریال، سرگرمی و لایو، کودک و سبک زندگی).

## 🚀 روش ساخت فایل نصبی (APK) بدون نیاز به نصب Android Studio (با GitHub Actions)

فایل ورک‌فلو گیت‌هاب (`.github/workflows/build-apk.yml`) داخل پروژه آماده است!

1. یک ریپازیتوری جدید در گیت‌هاب خود بسازید.
2. محتویات این فایل زیپ را در ریپازیتوری خود آپلود یا Push کنید:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: Dark TV Pro Android & TV App"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO.git
   git push -u origin main
   ```
3. وارد تب **Actions** در ریپازیتوری گیت‌هاب خود شوید.
4. گیت‌هاب به صورت خودکار پروژه را بیلد می‌کند و فایل نصبی آماده (`DarkTV-Release-APK`) را با حجم فوق‌العاده کم به شما تحویل می‌دهد!
